# 술친구 (MQ-3) — 프로젝트 개요 문서

> 라즈베리파이 기반 스마트 혼술 케어 시스템  
> 팀원: 이지현, 조윤정 | GitHub: [github.com/orgs/MQ-3](https://github.com/orgs/MQ-3/repositories)

---

## 1. 프로젝트 소개

**술친구**는 혼자 술을 마시는 사용자가 자신의 음주 상태를 직관적으로 확인하고, 과음을 예방할 수 있도록 돕는 라즈베리파이 기반 스마트 케어 시스템입니다.

MQ-3 알코올 센서로 호흡 중 알코올 반응값을 측정하고, 상태에 따라 웹 대시보드·RGB LED 피드백을 제공합니다. AI 숏츠 잠금해제 기능을 통해 사용자가 자발적으로 측정을 반복하도록 유도하며, 1인 가구와 혼술 문화가 늘어나는 환경에 맞춰 스스로 음주 상태를 점검할 수 있는 안전한 음주 환경을 목표로 합니다.

> ⚠️ MQ-3 센서는 의료기기 수준의 혈중알코올농도 측정기가 아닙니다. 이 시스템은 정확한 BAC 측정보다 **상태 인지와 즉각적인 피드백 제공**에 목적이 있습니다.

## 2. 시스템 구성

### 하드웨어 흐름

```
[첫 진입]
웹 대시보드 접속 → 바로 측정 유도
    ↓
사용자 호흡 (MQ-3 센서에 숨 불기)
    ↓
MQ-3 알코올 센서 (아날로그 출력)
    ↓
MCP3208 ADC (아날로그 → 디지털, SPI 통신)
    ↓
Raspberry Pi 4
    ├─ sensor.py   — 센서값 읽기
    ├─ state.py    — 음주 상태 판별 (safe / caution / danger)
    ├─ db.py       — SQLite 기록 저장
    ├─ app.py      — Flask 웹 서버 / API
    ├─ led.py      — RGB LED 제어
    ├─ shorts.py   — AI 숏츠 잠금해제 로직
    └─ reports.py  — 주간/월간 리포트
    ↓                              ↓
웹 대시보드 + RGB LED        숏츠 잠금해제 판정
(현재 상태·그래프·달력)       safe/caution → 다음 에피소드 해제
                              danger       → 잠금 유지 + 휴식 권장
                                   ↓
                         AI 숏츠 잠금화면 (다음 에피소드 보려면 재측정)
                                   ↓
[2회차 이후] ←─────────────────── 사용자 재측정 유도 (루프)
```

### 출력 장치

| 출력 | 설명 |
|------|------|
| Flask 웹 대시보드 | 현재 측정값, 상태 문구, 그래프, 달력 표시 (Wi-Fi 브라우저로 접근) |
| RGB LED | 상태별 색상 피드백 (초록 / 노랑 / 빨강) |
| AI 숏츠 | 측정 결과에 따라 잠금해제, 2회차 이후 재측정 유도 |

## 3. 음주 상태 판별 기준

| 단계 | level | 설명 | LED 색상 |
|------|-------|------|---------|
| 안정 단계 | `safe` | 현재 안정적인 상태로 추정 | 🟢 초록 |
| 주의 단계 | `caution` | 알코올 반응 감지 | 🟡 노랑 |
| 과음 주의 단계 | `danger` | 높은 알코올 반응 감지 | 🔴 빨강 |

임계값 (`config.py`에서 수정):
```
SAFE_MAX_VALUE    = 1200   # 미만이면 safe
DANGER_MIN_VALUE  = 2400   # 이상이면 danger
# 그 사이는 caution
```

## 4. 주요 기능

### 현재 구현 완료된 기반 기능
- Raspberry Pi 4 환경 구성 및 SPI 활성화
- MCP3208 연결 및 CH0 값 읽기 테스트
- Python 가상환경 구성
- Flask, spidev, gpiozero, pygame 패키지 설치

### 최종 목표 구현 기능

**측정 & 판별**
- MQ-3 알코올 반응값 측정 (mock 모드 지원)
- MCP3208 기반 아날로그-디지털 변환
- 센서값 기반 음주 상태 3단계 판별

**웹 대시보드**
- 현재 측정값 / 상태 / 안내 문구 실시간 표시
- 일간 측정값 그래프
- 주간 / 월간 기록 달력 (상태별 색상)
- 술 종류 및 술 양 입력

**데이터 저장**
- MySQL 기반 음주 기록 저장 (`drink_logs` 테이블)

**LED**
- 측정 게이지 연출
- 측정 완료 후 상태별 색상 피드백

**AI 숏츠 (술친구 핵심 기능)**
- 첫 웹 진입 시에는 조건 없이 바로 측정
- 측정 결과에 따라 다음 에피소드 잠금해제 여부 결정
  - safe / caution → 다음 에피소드 잠금해제
  - danger → 잠금 유지 + 휴식 권장 화면 표시
- 2회차 이후: 잠긴 숏츠 화면이 사용자의 재측정을 자연스럽게 유도 (반복 루프)
- 측정 간격 15분(영상 길이 15분)

## 5. API 명세 요약

서버 주소: `http://192.168.30.7:5000` (로컬: `http://127.0.0.1:5000`)  
전체 응답 형식: JSON

| 메서드 | 엔드포인트 | 설명 |
|--------|-----------|------|
| GET | `/api/health` | 서버 상태 확인 |
| POST | `/api/db/init` | DB 테이블 초기화 |
| POST | `/api/measure` | 센서 측정 및 상태 판별 |
| POST | `/api/logs` | 음주 기록 저장 |
| GET | `/api/logs/today` | 오늘 기록 조회 |
| GET | `/api/logs/week` | 이번 주 요약 |
| GET | `/api/calendar/month` | 이번 달 달력 데이터 |
| GET | `/api/shorts` | 숏츠 목록 및 잠금 상태 조회 |
| POST | `/api/shorts/unlock` | 술친구 체크인 (측정 + 잠금해제 시도) |

자세한 요청/응답 형식은 `API_SPEC.md` 참고.

## 6. 레포지터리 구조

### `MQ-3/raspberry` (Python — 백엔드 + 하드웨어)

```
raspberry/
├── app.py            # Flask 메인 서버
├── sensor.py         # MQ-3 센서값 읽기

├── led.py            # RGB LED 제어

├── adc.py            # MCP3208 ADC 제어
├── mcp3208_test.py   # ADC 테스트 스크립트
```

## 10. 한계 및 참고사항

- MQ-3는 상대적인 알코올 반응값을 측정하는 센서이며, 센서 예열 상태·거리·주변 환경에 따라 측정값 오차가 발생할 수 있습니다.
- 실시간 상태 표시와 즉각적인 피드백에 집중하는 구조로, 별도의 복잡한 데이터 파이프라인은 사용하지 않습니다.
- 개발 상황에 따라 기능 추가 또는 변경이 있을 수 있습니다.
